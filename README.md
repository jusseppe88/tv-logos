# tv-logos

Uniform channel logos for a personal Plex Live TV guide (Dispatcharr HDHR tuner).

- `logos/<dispatcharr channel id>.png`: 600x400 transparent PNG, artwork trimmed and scaled to fill the 3:2 box Plex uses, with a light panel behind logos that are too dark for Plex's dark guide.
- Served through commit-pinned jsDelivr URLs, `https://cdn.jsdelivr.net/gh/jusseppe88/tv-logos@<commit>/logos/<id>.png`, so a new commit gives Plex new URLs to fetch.
- Logos are trademarks of their owners and are used here only to label channels.
